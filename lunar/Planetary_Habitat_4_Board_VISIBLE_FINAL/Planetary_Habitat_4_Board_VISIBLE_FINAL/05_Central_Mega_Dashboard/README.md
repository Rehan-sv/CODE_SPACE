# Optional Central Mega Demonstration

This is a separate Wokwi simulation because Wokwi currently does not support multiple microcontrollers in one project. The four member boards therefore remain individually executable, while this Mega project demonstrates the central dashboard behavior and the final physical pinout: Mega SDA=20, SCL=21.

The four potentiometers stand in for the four node health values so the dashboard can be demonstrated independently.
